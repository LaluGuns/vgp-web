# Project skills

Copy rules for every user-facing word on the public site (`docs/DESIGN.md`).
Both are vendored verbatim from upstream under the MIT licence (see each
folder's `LICENSE`). To update, replace the files with the upstream ones.

| Folder | Upstream | Version vendored (2026-10-09) |
|---|---|---|
| `humanizer/` | https://github.com/blader/humanizer (`SKILL.md`) | 3.1.0 |
| `antislop-copywriting/` | https://github.com/miqdadbadjuber/anti-slop (`skills/antislop-copywriting/SKILL.md` + core `antislop.md`) | v3.2.20 |

In this repo antislop runs in **during** mode for all copy work: apply the
rules while writing and finish with the copywriting checklist. Do not stop
to ask for a mode. The UI parts of `antislop.md` are reference only;
`docs/DESIGN.md` is the design direction.
